# WAVE-07 — One-command asset build and cross-language asset check
Depends on: WAVE-03, WAVE-06
Human prerequisites: none

## Tasks
### T07.1 — `flybrain build` and the full CLI
- Files: `pipeline/src/flybrain_pipeline/build.py`, `pipeline/src/flybrain_pipeline/cli.py`, `pipeline/tests/test_build.py`, `pipeline/tests/test_cli.py`, `pipeline/tests/data/raw/**`
- Do:
  1. Create tiny raw inputs in `pipeline/tests/data/raw/` using exactly the paths of [PLAN-01 §2b](PLAN-01-architecture.md#2b-raw-data-layout---raw-default-pipelinedataraw-gitignored): `body/flybody/flybody/fruitfly/assets/fruitfly.xml` (3 inline-mesh bodies), `body/walking/ref.hdf5` and `body/flight/ref.hdf5` (20 frames), `spikes/<behavior>.parquet` × 4 (~50 neurons), `brain/neuropils.npz` (3 neuropils), `brain/skeletons.npz` (5 neurons), `brain/per_neuron_neuropil_count_post_783.feather` (50 rows), `brain/annotations.tsv` (10 rows), `config/keyframes.toml` and `config/stimuli.json` matching the tiny MJCF. Total < 300 KB.
  2. `build(raw_dir, out_dir, config, compress=True) -> Path`: body nodes + 4 clips → `fly.glb`; neuropils → `brain.glb`; neurons → `neurons.glb`; channel map + spikes → `activity/<behavior>.bin`; `manifest.json` with `dataSource` (`flywire-783` unless `--fixture-raw`), stimulus info from `stimuli.json` (including `assumption`), `clipSource` per behavior, attribution rows from [RESEARCH-03](RESEARCH-03-licences-citations.md), `narrationUrl: /narration/<behavior>.json`.
  3. When `compress`, run `npx --no-install gltf-transform optimize <in> <out> --compress meshopt` per glb (`subprocess.run(check=True)`, list args, no shell); then `npx --no-install gltf-transform validate`.
  4. Validate the manifest with `validate.py` and run `budget.check`; any error → exit 1 with the list. Write to a temp dir next to `out_dir`; only on success, move any existing `out_dir` to `out_dir.old`, rename temp → `out_dir`, then delete `out_dir.old` (safe to re-run; no half-written assets).
  5. `build` flags: `--raw`, `--out`, `--fixture-raw` (sets `dataSource: fixture`), `--points` (neuropils as point clouds from the synapse table), `--no-neuron-lines` (omit `neurons.glb` skeleton lines; neurons still exist as activity channels), `--no-compress`. Keyframes and stimuli come from `<raw>/config/` when present, else `pipeline/config/keyframes.toml` and `pipeline/sims/shiu/stimuli.json`. All flags as in PLAN-01 §2b. `fetch-brain` lives in `build.py` as `fetch_brain_main`: it always calls `brain_neurons.select_neurons` and writes `brain/selected_neurons.json`; it calls `brain_neuropils.fetch_neuropil_meshes` unless `--skip-neuropils` and `brain_neurons.fetch_skeletons` unless `--skip-skeletons` (fafbseg imported only then, so `--skip-neuropils --skip-skeletons` needs no token and no `fetch` extra). `build` reads curated ids from `brain/selected_neurons.json`; if the file is missing it calls `select_neurons` itself with the same arguments.
  6. `cli.py` subcommands: `fetch` (→ `fetch.main`), `fetch-brain` (selection, plus neuropil meshes and skeletons unless skipped; the `fetch` extra is needed only for those), `build`, `fixtures`, `validate`, `budget`, plus `--version`. Each delegates to the module's `main`.
- Tests: `pipeline/tests/test_build.py` — build from `tests/data/raw` with `compress=False` into tmp: manifest validates, all URLs exist, activity sizes right, 4 animations named by behavior, failed validation leaves `out_dir` untouched; a second build into the same `out_dir` succeeds; with `brain/selected_neurons.json` present, build uses exactly those ids; with it removed (tmp copy of the raw dir), build falls back to `select_neurons` and gives the same ids; `fetch_brain_main` with `--skip-neuropils --skip-skeletons` writes only `selected_neurons.json` and never imports `fafbseg` (assert via `sys.modules`); with `compress=True` when `npx` is available. `pipeline/tests/test_cli.py` — each subcommand dispatches (monkeypatched mains), unknown subcommand exits 2.
- Acceptance: `uv run --directory pipeline pytest tests/test_build.py tests/test_cli.py --no-cov && uv run --project pipeline flybrain build --raw pipeline/tests/data/raw --out /tmp/flybrain-build-check --fixture-raw`
